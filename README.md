# FPGA Market Data Accelerator

This is a SystemVerilog project I’m building to learn more about FPGA design, low latency hardware, and packet processing.

Right now I’m starting with a simple packet parser that takes in bytes and pulls out useful data from a packet.

## Goals

- build a packet parser in SystemVerilog
- make a testbench and verify it works
- learn more about FSMs and pipelining
- eventually measure latency and throughput
- keep adding more realistic market data processing later

## Current Progress

Just getting started. Working on the first packet parser module.
